# Project: Gemini CLI API Wrapper

## Vision
A lightweight, efficient, and compatible REST API gateway for the Gemini CLI, enabling developers to leverage Google's models with OpenAI-compatible interfaces and advanced account management.

## Core Objectives
- **OpenAI Parity:** Provide a drop-in replacement for OpenAI-compatible tools and SDKs.
- **Account Management:** Enable seamless switching between different Google accounts/API keys.
- **CLI Power:** Leverage the higher rate limits and session management of the Gemini CLI.
- **Security:** Ensure safe programmatic access to Gemini models.

## Stakeholders
- Developers seeking higher rate limits for Gemini.
- Users of OpenAI-compatible tools (e.g., LibreChat, Continue.dev).
- System administrators managing multiple Gemini accounts.
